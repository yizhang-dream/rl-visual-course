一个术语，全书哪里讲过？One term, every section that teaches it

关键术语的反向索引：每个术语列出全书十讲中它出现过的所有小节，逐条深链直达课堂对应位置。术语表由脚本对全书小节文本构建期扫描生成（ npm run build:concordance ），匹配中文名、英文名与站点行文的别名写法。 A reverse index of key terms: each term lists every section of the ten lectures where it appears, with deep links into the classroom. The table is generated at build time by scanning section text (npm run build:concordance), matching Chinese names, English names and the site's own wording.
